# Library

Лендинг для библиотеки, который включает функционал регистрации и входа в личный кабинет с сохранением данных в Local Storage. Пользователи могут приобретать абонементы и добавлять книги в свою карточку.

## Ссылка на проект:

[Посмотреть проект](https://almazka-code.github.io/library/)

## Реализованный функционал:

- Регистрация и вход в личный кабинет
- Сохранение данных в Local Storage
- Приобретение абонементов
- Добавление книг в карточку
- Карусель с плавной анимацией переключения
- Переключение между категориями с помощью табов
- Адаптивная верстка для оптимизации отображения на различных устройствах
- Бургер-меню для улучшения навигации на мобильных устройствах

## Технологии и инструменты:

- **HTML**: создание структуры страниц и разметки контента
- **SCSS**: стилизация компонентов
- **JavaScript**: реализация интерактивного функционала без использования сторонних библиотек
